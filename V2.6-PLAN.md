# ABDULKAREM AI X v2.6 — Model Arena & Adaptive Routing

Base: `v2.5.1`

UI baseline: **Codex-fixed v2.5.1 interface preserved.** This release intentionally does not modify the renderer layout, right panel, capability grid, composer, or responsive UI.

## Added

- Local Model Arena engine.
- Adaptive model routing that automatically reads persisted Arena results.
- Benchmarks for Coding, General, Reasoning, and Tool Use.
- Optional Vision capability benchmark path.
- Health states: READY, SLOW, DEGRADED, COOLDOWN, OFFLINE.
- Weighted routing score:
  - Quality 40%
  - Reliability 20%
  - Task Match 15%
  - Speed 10%
  - Tool Accuracy 10%
  - Resource Efficiency 5%
- Fallback-chain generation with duplicate prevention.
- Routing explanation and confidence.
- Local routing-decision audit JSONL.
- Runtime-result learning API in `ModelArena.recordRuntimeResult()`.
- Protected-model invariant for `qwen3-coder:30b`.
- `npm run arena` for live Ollama benchmarking.
- `npm run arena:dry` for non-destructive dry verification.
- Model Arena and Adaptive Routing regression tests integrated into `npm run check` and `npm run release:gate`.
- GitHub CI for source checks, release gate, renderer build, and protected-model guard.

## Adaptive routing behavior

When no Arena state exists, routing remains compatible with v2.5.1 static priorities.

After running:

```powershell
npm run arena
```

Arena results are saved by default to:

```text
%USERPROFILE%\.abdulkarem-ai-x\model-arena-v2.6.json
```

The existing `selectModelFromInstalled()` path then automatically uses the Arena scores. No renderer change is required.

Routing decisions are audited to:

```text
%USERPROFILE%\.abdulkarem-ai-x\routing-decisions-v2.6.jsonl
```

## Safety invariants

```text
qwen3-coder:30b = PROTECTED
```

v2.6 adds no model deletion command and no automatic cloud approval.

## Commands

```powershell
npm ci
npm run check
npm run release:gate
npm run arena
npm run build
```

To benchmark selected models only:

```powershell
node scripts/model-arena.js --model=qwen3-coder:30b --model=qwen3:8b --max=2
```

To benchmark selected suites:

```powershell
node scripts/model-arena.js --kinds=coding,general,reasoning,tools
```
