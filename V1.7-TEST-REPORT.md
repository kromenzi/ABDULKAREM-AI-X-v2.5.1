## Runtime behavior covered

1. A packaged build uses its own executable plus `--background` for Windows login startup.
2. A source ZIP uses hidden PowerShell and `BACKGROUND-RUNTIME.ps1` so Vite remains available when the Tray later opens the UI.
3. Closing the window keeps the Electron main process alive only when Background Mode + Close-to-Tray are enabled.
4. Exit from the Tray is the explicit full shutdown path.
5. Scheduler controls are available from the Tray.
6. Workflow/Automation waiting-approval events can create native notifications without auto-approving anything.
7. A second application instance is blocked by Electron's single-instance lock and routes the user back to the existing instance.
